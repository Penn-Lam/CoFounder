# Use Jev only for bounded, replaceable classification

Generate results through three layers: deterministic Rules produce a de-identified Pair Feature Vector, a pinned Jev model selects bounded typed content identifiers for genuinely fuzzy judgments, and a versioned human-authored Content Library supplies every visible word. Exact arithmetic, thresholding, conflict detection, Mirror Accuracy, and numerical ranking remain in Rules. Jev receives no raw answers or Account data; its model version, decision schema, probabilities, confidence, and output are persisted with the result.

Report generation runs asynchronously through Cloudflare Queue. A classifier interface keeps Jev replaceable, and low confidence, timeout, rate limit, or provider failure produces a complete Conservative Result from deterministic Rules instead of blocking Pair Completion. Confidence thresholds must be calibrated against a labelled evaluation set before launch. This preserves Jev's value for archetype and narrative salience without making an early-access external model a correctness or availability dependency.

Call TypeSafe's official System One API first with `JEV_API_KEY`. Use the OpenRouter System One endpoint with `OPENROUTER_API_KEY` only when the official endpoint is unavailable, rejects the request, or returns malformed output. Evaluate eleven bounded Choice questions in one request: Public Archetype, strongest alignment, valuable complement, top ordinary risk, Mirror interpretation, Private Risk Pattern, and five non-overlapping conversation-prompt slots. Apply confidence independently per question so one uncertain answer does not discard the other decisions. A valid low-confidence official answer uses that question's deterministic fallback rather than shopping for a more confident answer from another gateway. Use the fixture-calibrated default threshold of `0.3` for these bounded, non-generative choices and allow an environment override. The calibration covers 81 deterministic boundary fixtures and 20 synthetic narrative Pairs; at `0.3`, Jev retained the same approved-Archetype coverage as no threshold while 20.9% of all sub-decisions used a fallback. Persist the provider, per-question probabilities, confidence, fallbacks, and selected content IDs.
